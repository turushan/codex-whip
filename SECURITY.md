# Security

Please report security problems privately, not in a public issue.

Use [GitHub's private reporting](https://github.com/turushan/codex-whip/security/advisories/new),
or email turushande@gmail.com. Describe the problem and the steps that show it. You will get a
reply within a few days.

Fixes ship in the latest release, through the app's signed automatic updates. Older versions do not
receive separate fixes.
